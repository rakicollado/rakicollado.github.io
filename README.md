# Glass Portfolio Website

A white/gray glassmorphism portfolio template with a subtle animated background.

## Files

- `index.html` — page structure and editable content
- `styles.css` — glassmorphism design, layout, and responsive styling
- `script.js` — mobile navigation, active section state, and background animation
- `assets/` — put your profile photo or certificate images here

## How to edit

1. Open `index.html`.
2. Replace `Raki Collado`, contact details, resume entries, skills, and certificates.
3. To add a profile picture, put your image in `assets/profile.jpg`, then replace the initials block in `index.html` with:

```html
<img src="assets/profile.jpg" alt="Raki Collado" class="profile-photo" />
```

## How to publish on GitHub Pages

1. Upload the files to your GitHub Pages repository.
2. Keep `index.html` in the root folder.
3. Commit and push.
4. Visit your GitHub Pages URL.
